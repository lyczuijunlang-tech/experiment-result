# 车载 ISAC 跨周期反馈实验

图7–9在跨周期反馈下分配感知资源，并按原论文的单周期加权 CRB 评分。每个周期用上一周期的后验状态和协方差预测目标状态，再依据预测的 TTC 权重和 LFM 等效 Fisher 信息分配资源。图中 CRB 只由本周期的 LFM 测量信息计算。
