# 车载 ISAC 递推资源分配与后验 TTC-CRB 约束

本研究用上一周期的后验状态和协方差预测当前目标状态。P1 在风险加权后验 CRB 目标下分配驻留时间，P2 更新系统感知时间和功率。图1–4在每个正式周期和指定扫描点重跑，加入针对预测闭合目标的相对后验 TTC-CRB 门限。

主图采用6.4%（图1、图3）、11%（图2五方法）和12%（图4开关组）的相对标准差下界门限。图1–3采用单周期加权测量下界$\omega\mathrm{CRB}$，图4采用加权跟踪后验下界$\omega\mathrm{PCRB}$。

图号已由7、8、9、10统一改为1、2、3、4，图2保留(a)–(c)三联图。图片、CSV、绘图入口及发布清单同步使用新编号。图4的文件名为fig4_total_wpcrb，CSV列名为wPCRB_ON和wPCRB_OFF。本次仅修改编号及指标标识，所有实验数值保持不变。
