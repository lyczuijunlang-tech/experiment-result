# 跨周期后验 CRB 反馈实验

本实验将上一周期的后验估计与误差下界反馈给下一周期。使用 [inputs](inputs/) 中记录的 SUMO 轨迹，保留四个固定目标、0.1 s 决策间隔、40 s 时域、原 LFM 雷达参数及驻留时间、通信速率、功率和能量约束。

图7和图9的原配置通过仓库根目录下的 `python 实验/run_latest.py` 复现。图8(b)(c)的等 RCS 扫描使用 `python 实验/run_latest.py --figure8-minmax`。图8(a)的弱回波工况在该命令后加 `--fig8a-k3-rcs-m2 2.5`。此设定对五种方法统一生效，且同时作用于预测和实测模型中的 k3 雷达方程。各时域入口从 −2 s 发现目标并完成 19 次预热更新。图8(a)的五种方法各自跟踪。图7和图8(b)(c)冻结 40 s 的平均预测协方差用于求解资源。图7–9使用原单周期 LFM 测量 FIM 的逆矩阵计算加权 CRB。图9对应原配置的逐目标贡献。

图8的第三种方法 Min–Max AO 优化四个目标中最差的后验 CRB。它和 TTC-AO 一样将历史后验协方差递推为当期先验 `P_k^-`。设 `W` 为原距离和速度方差归一化矩阵，则目标级下界为 `C_k⁺(t_k,P_s)=tr(W[(P_k^-)⁻¹+J_k(t_k,P_s)]⁻¹)`。固定系统总时间和功率时，P1 在 `C_k⁺ ≤ z`、`t_k ≥ t_min`、`Σt_k=T_s` 下最小化 `z`。各 `C_k⁺` 随驻留时间单调下降，代码对阈值求根，使所需驻留时间之和恰好等于预算。P2 沿用公共的总时间、功率更新和约束。绘图统一使用原单周期 `ωCRB`。最差目标精度的优化思路可参见 [Li 等的多目标雷达资源分配工作](https://doi.org/10.1049/iet-rsn.2020.0332)。

以下另说明双方法 RMSE 验证入口，该入口从 −0.1 s 初始化。

每个目标的状态为 `x = [距离, 径向闭合速度]`。闭合速度为正时距离减小。跟踪器读取上一周期的后验状态估计和 2×2 后验协方差，按 `x⁻ = F x̂`、`P⁻ = F P⁺ Fᵀ + Q` 预测。本次采用局部恒闭合速度模型，`F = [[1, -Δt], [0, 1]]`。连续白相对加速度谱密度为 0.02 m²/s³。发现阶段用 t = −0.1 s 的模拟观测初始化，距离和闭合速度观测标准差为 0.2 m 和 0.1 m/s。波束使用上一周期的方位读数，方位读数噪声标准差取 0.2°。这些参数是本实验的模拟设定。

预测的距离、闭合速度和方位用于计算 TTC 权重和原 LFM 等效 Fisher 信息矩阵 `J_LFM`。给定候选感知资源，设计端计算 `P⁺ = [(P⁻)⁻¹ + J_LFM]⁻¹`，再对距离和闭合速度的归一化对角项做 TTC 加权求和，得到标量 wPCRB。下一周期递推使用各目标的完整 2×2 矩阵。上一周期的标量 wPCRB 也写入日志，便于逐周期追溯。

P1 仍分配目标级驻留时间。单帧目标沿用原 KKT 求解器。后验目标改用多初值 SLSQP，并把上一块的可行分配纳入候选，保证接受的块更新目标值不增。P2 先固定功率更新时间，再固定时间更新功率。原 LFM 信息下，放大所有驻留时间并按比例降低功率能保持测距信息并增加测速信息，因此在原约束下可以直接取通信 QoS 允许的最大感知时间，再取可行最大功率。P1 的多初值结果是数值解，未做全局最优认证。

选定资源后，模拟器按该周期的 SUMO 真值、实际指向增益及 LFM 信息矩阵生成带噪测距和测速读数。跟踪器使用设计端的预测信息执行卡尔曼更新。SUMO 目标真值用来模拟读数和计算误差，当前自车位置用于原通信约束。该实验使用等效高斯测量模型，wPCRB 是局部线性高斯设计模型的名义下界。真实交通存在模型失配，不能把该下界直接当成实测误差或任意非线性交通模型的严格界。

同一 SUMO 路径使用 16 组独立测量噪声重复。两种资源优化方法共享初始误差和标准正态噪声样本，各自执行预测和滤波。两组都保留历史，区别是分配资源时分别最小化 wPCRB 和原单帧 wCRB。额外对照直接使用后验分配组的同一份本帧读数，用于隔离滤波历史的作用。图中下界是跨噪声重复的算术平均，RMSE 汇总每一时刻四目标和全部重复的平方误差。图中没有平滑或强制跨周期单调。

在仓库根目录执行以下命令。依赖沿用图8(a)的 Python 环境。输出路径需是一个新目录。

```text
python 实验/latest/recursive_feedback/run_feedback.py --output 结果/recursive_feedback_rerun
python 实验/latest/recursive_feedback/plot_feedback.py 结果/recursive_feedback_rerun
```

`tracking.csv` 记录每个目标的前一周期协方差、预测、资源、测量和后验估计。`cycle_metrics.csv` 记录每周期三个资源求解阶段的下界以及 RMSE。`run_config.json` 记录噪声参数、种子和输入哈希。`summary.json` 汇总整段、前 50 周期和末 50 周期。

递推下界的理论背景见 [Tichavský、Muravchik 和 Nehorai 的论文](https://www.ese.wustl.edu/~nehorai/paper/ieeetsp98-1.pdf)。
