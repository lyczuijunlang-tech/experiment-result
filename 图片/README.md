# 车载 ISAC 实验图

各图提供 PNG、PDF、SVG。总量的图中标注统一为 $\omega\mathrm{CRB}=\sum_k\omega_k\mathrm{CRB}_k$。图7–9仍采用原论文定义的单周期加权下界，图8横坐标依次为 t(s)、d(m)、v(m/s)。图9的四条曲线各为一个目标的加权贡献，因此纵轴标注 $\omega_k\mathrm{CRB}_k$，图上方给出总量公式。
